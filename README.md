## ✨ 这是什么

一套给**不懂代码的产品经理 / 学生**的开箱工具包。把它交给一个能操作你电脑的编码 AI（Claude Code、Cursor、Codex 等），贴一句启动句，AI 就带你从"一个想法"走到"上线产品"——写代码、跑测试、做界面、部署上线，全由 AI 完成；你只做少量"必须本人才能做"的事。

## 🎯 它解决什么问题

| 你的处境 | 这个工具包给什么 |
| --- | --- |
| 有产品想法，但不会写代码 | AI 替你写全部代码，你只做业务判断 |
| 网上教程太技术、太碎片 | 内置三份技术手册，AI 按阶段自动读取 |
| 不知道"做到哪算好" | 每个阶段有明确闸门和证据包，你能自己核对 |
| 卡在云平台、密钥、备案 | 上线阶段有"照着点"清单，注册/认证/开权限都有引导 |

## 🚀 快速开始（约 1 分钟）

1. 把整个文件夹放到你电脑上（压缩包先解压，**不要改里面文件**）。
2. 用一个**能读写文件、执行命令的编码 AI 工具**打开这个文件夹（网页版纯聊天 AI 不行）。
3. 在对话框贴这句话：

   ```text
   请读取项目根目录的 AGENTS.md，按其中"启动流程"开始。
   ```

4. AI 会根据你的情况自动走流程（有没有 PRD、是不是接着上次做）。之后每一步 AI 都会告诉你"下一步做什么"；看不懂就说"用产品语言再说一遍"。

> 📖 完整操作手册见 [开始看这里.md](./开始看这里.md)。

## 🧭 六个阶段

| 阶段 | 内容 | 你要做的 | 通过条件 |
| --- | --- | --- | --- |
| 0 PRD 体检 | 检查 / 补全产品需求 | 回答问题（≤5 个/轮，可回"按推荐"） | 补全清单全部关闭 |
| 1 技术适配 | 定技术方案 | 确认理解对不对、有无多出费用/范围 | 决策台账无影响本阶段的待定项 |
| 2 后端 MVP | 核心能力 + 真实验证 | 提供 Key、给真实结果打分、照清单验收 | 证据包已交 + 闸门全"是" |
| 3 正式前端 | 界面 + 移动端 | 给视觉方向、看代表页、真机走一遍 | 同上 |
| 4 上线 | 部署到云 | 注册/认证、控制台照着点、验收 | 验收清单全过 |
| 5 收尾 | 整理 + 删密钥 | 删云密钥 | 状态文件记录完成 |

每个阶段结束，AI 必须交**证据包**（截图 + 可打开地址/照着点步骤 + 是否表）。是否表有"否"就不能说完成。

## 🔒 内置的强制底线

这套规则卡约束 AI，你可以放心：

- 🔑 密钥不进仓库、不进前端、不回显
- 💾 数据可恢复，重启不丢
- ✅ 真实模型验证，不拿 mock 结果冒充
- 💰 涉及花钱的云资源，先告知费用再动手
- 🔐 用户只能看自己的数据
- 🛡️ 错误不泄露技术堆栈

## ❓ 常见问题

**要花钱吗？** 两处：模型 Key（按用量付费，AI 会帮你估）；上线云费用（上线前会估，创建前必须经你确认）。开发期可先不买 Key，AI 用模拟数据推进。

**必须企业认证吗？** 正式上线的默认方案需要云平台企业认证。没有的话，AI 先用临时方案上线并明确三条限制，认证办好后再切换。

**AI 说做完了，我怎么信？** 看证据包：截图 + 可打开的地址 + 是否表。有"否"就不算完成。

**可以中途换模型 / 换工具吗？** 可以。规则和进度都存在文件夹里（`docs/项目状态.md`），不依赖某个模型的内存。

### A5 补丁预览与安全写入
演示地址：<http://127.0.0.1:3000/projects/8777039d-241e-4050-bf97-18ab588f31bb/patches>。页面有三份不可变补丁、成功及已恢复运行。主目录 demo.txt 现为冲突测试的外部文本，历史成功记录不表示此后的文件仍等于旧候选。

先在执行页保存显式文件范围并确认本地零费 code_write 范围；补丁页选任务、添加文件、填写完整候选和验证计划，点“保存补丁预览”。核对文件、差异、来源和验收要求，勾选确认并填依据，才可点“确认并写入此补丁”。API 成功返回运行记录，applied 仅表示文件写入，仍需工程验证。网络异常先刷新查看运行；同一补丁已有运行时不会重复应用，修改须另存预览。

范围：最多 5 个 UTF-8 文件，每份原文/候选不超过 64 KiB、合计 256 KiB，父目录必须存在；只新增/替换，不删除、改名、建目录。拒绝越界、秘密、符号/硬链接、非普通文件、原始数据、依赖配置、数据库及已知迁移路径/SQL 变更。平台工程及运行数据不能作为业务补丁目标；嵌套登记的另一项目受保护。启发式秘密/SQL 检查仍需人工核对，不承诺理解所有代码语义。

前置来源和 15 分钟环境、当前执行修订、授权、显式文件、未完成依赖、独占锁和待恢复运行由后端重新检查；每个写步骤重新核对授权。撤销可能发生在已完成一步之后，此后停止并尝试补偿。补丁原文、候选和私有副本长期本机保存，不进日志或 Git。启动时恢复未结束写入，第三方内容阻止自动恢复并显示 rollback_required；操作者可人工解决冲突后点“重新核对安全恢复”。恢复不覆盖未知第三方内容；补偿不是跨进程多文件原子事务，不能替代数据库恢复。

后端 GET/POST 接口定义在 A5 文档与 patch_schemas.py。自检可运行 .venv/bin/pytest backend/tests/test_patches.py -q，其中故障与进程退出只针对临时文件，不操作已登记的真实项目。没有真实模型 Key，仍为待验。
