# 配置说明

启动入口自动创建本机访问令牌，浏览器通过代理访问后端。默认模型关闭；如需启用，在提供方配置页填写自己的服务信息，再按项目明确外发授权与预算。根目录 `.env.example` 是配置提示，服务参数以进程环境变量和本机配置页为准。

| 配置 | 位置 | 作用 |
| --- | --- | --- |
| FACTORY_DATA_DIR | 进程环境变量 | 默认根目录 data，包含数据库与访问令牌 |
| FACTORY_ALLOWED_ROOTS | 进程环境变量，JSON 数组 | 允许接入的现有目录，默认仓库根目录 |
| AI 提供方配置 | 工作台设置页 | 模型默认未启用；Key 存本机，不进入仓库 |
| 服务端口 | 统一启动脚本 | 后端 8765 / 前端 3000；占用时拒绝启动 |

## 本机数据与验证

`frontend/` 为 Next.js 工作台，`backend/` 为 FastAPI / SQLite / Alembic，`scripts/run_local.py` 管理本项目服务。

各项目端口可能重叠，分别运行时先停止自己启动的前一项目，或按各项目配置调整端口与代理。密钥、业务数据、模型文件、依赖和构建产物留在本机，不进入公开仓库。克隆仓库不会带入原电脑的模型配置、邀请码数据库或费用额度。

以下为离线工程检查入口；历史真实模型脚本可能产生费用，请先阅读对应验收记录。

```bash
.venv/bin/ruff check backend scripts
.venv/bin/mypy backend/app scripts
npm --prefix frontend run lint
npm --prefix frontend run typecheck
npm --prefix frontend run build
```
