# 阶段 2 A6 技术开发文档｜命令执行与运行记录
> V1.1，2026-10-08，工程交付与待验。V1.0 已在编码前形成，本版补充实现、验证与交接；遵循先文档、再开发验证、最后本地提交。依据主 PRD V1.1 FR10、FR08、AGENTS 及阶段 1 技术适配；A1—A5 待验保留，工程推进不等于阶段通过。

## 一、阶段目标
交付具体配方预览 → 明确批准 → 持久运行 → 真实操作系统子进程 → 有限脱敏日志、步骤、退出码、产物、错误的链路。提供服务进程归属、端口、真实健康与停止入口，端口冲突不结束无关程序。
首批批准能力：Python 语法检查（只解析不执行代码）、JSON 格式检查、受限 HTML/CSS 静态预览。真实执行可信平台程序，不把模拟输出当真实命令。
项目任意 shell、npm/pytest 脚本、安装、外发、发布、数据库迁移及完整应用执行器本轮不开放，界面标明手动执行待核对；后续能力按审批配方扩展，不降低 FR10 或全部 P0 范围。

## 二、技术适配摘要
延续 Python/FastAPI/SQLite/Alembic、Next.js，无新增依赖。纵向切片展示本阶段最小验收界面。
读取显式文件的不可变限量快照，用可信平台程序处理；不执行项目文件或包脚本。工作目录为私有运行目录，所属项目与实际工作目录分别说明。共享 A5 根目录身份独占锁和持久占用记录，保守地串行同项目操作。
本阶段必要的排队/进程意图/退出状态持久化与启动失联核对属于 FR10 最低恢复前提，不提前交付 FR11 通用接续、FR12 暂停取消及自动重试平台。

## 三、技术栈与模型
标准库 subprocess、selectors、socket/http.server、ast/json；shell=False，固定受信 Python 绝对路径、隔离模式和参数白名单。子进程不继承模型 Key、本机令牌或用户环境。
无模型调用、无新增费用、无资料外发、无云创建。原阶段预算不重置。

## 四、环境与配置
沿用工厂 3000/8765、本机来源与后端令牌。预览端口限定 4200—4299，只监听 127.0.0.1；静态页最多存活 600 秒，单次检查最长 30 秒，可选 1—30 秒超时。
每次最多 5 个已存在 UTF-8 文件，每份 64 KiB、总 256 KiB，沿用秘密/链接/原始数据/平台工程保护。静态仅显式 .html/.css，须含 index.html；服务不列目录，不读取项目其他文件。
输入快照和结果长期本机保存于忽略的 data/；目录 0700、文件 0600；脱敏运行日志保留 30 天，过期显示已到期而不是伪造空成功记录。

## 五、项目结构
追加 command_schemas.py、commands.py（预览/运行/工作线程/服务记录）、recipe_runner.py（可信固定配方）、0006 迁移和 commands 验收页；复用已有来源、范围授权、占用锁。保持旧模块、数据和测试。

## 六、数据、资产与状态
CommandAsset：id/project_id/execution_id、不可变 payload 与创建时间；绑定具体 local_command 步骤、来源/授权影响哈希、配方版本/程序哈希、文件身份/内容哈希、限时与端口。内容快照仅本机私有保存，不返回完整正文、不记日志。
CommandRun：id/project_id/asset_id、state/details/created_at。记录 queued → starting → running / serving → succeeded / failed / timed_out / stopped / interrupted；服务到期为 stopped，不自动重启。记录开始/结束、真实退出码、进程 ID、步骤、健康、错误、产物与有限脱敏日志。
幂等键绑定同一运行，刷新不新建。同一预览只有一次运行，重跑必须新预览并重新审阅。
启动前持久化 starting 再创建子进程。进程异常终止/平台重启后未终结运行标 interrupted/待核对，禁止按历史 PID 杀进程或自动重放。可信服务监测父进程死亡自行退出；正常平台关闭只结束自身已持有的子进程组。
macOS 在进程组退出瞬间拒绝信号时，回退到仍由 Popen 持有的未回收子进程。工作线程异常会被观察并保存为失联；未确认停止的运行继续阻止同项目命令与补丁，不自动重发。
静态服务占用目录锁直至结束，A5 补丁与其他运行须等待；其他项目可按有限资源上限执行。外部文件/来源/授权变化时停止此服务，保留已有记录与快照。

## 七、API / 工具设计
前缀 /api/v1/factory/projects/{id}/commands。POST 要求本机来源、幂等键；全部接口定义输入输出，错误统一 error.code/message，不返回堆栈。
- GET：配方目录（能力/限制）、预览历史、运行摘要。
- GET /assets/{id}：具体 argv、输入范围、来源版本、需求关联、验证要求、超时/日志上限与当前阻塞原因。
- POST /preview：execution_id/expected_hash、recipe_id（python_syntax/json_validate/static_preview）、step_id（多个命令步骤时必须明确）、files、timeout_seconds、port（仅静态）。仅保存可审查结果，不执行。
- POST /start：asset_id/expected_hash、confirmed=true、reason；重新核对后返回运行。当前执行须包含 local_command，本地零费范围授权有效，依赖无未验证结果。批准的是具体配方与快照，不是任意命令。
- GET /runs/{id}：持久步骤、退出码、产物、限量日志及健康；提交后轮询，HTTP 不等待长任务。
- GET /runs/{id}/artifact：返回结构校验后的结果元数据，重新核对保存时的大小及 SHA-256；产物被修改时返回冲突，不返回输入正文。
- POST /runs/{id}/stop：confirmed=true；只停止本次已持有的进程，持久请求与最终生效状态。不存在执行器的能力不能返回自动完成。
程序输出为严格有限元数据契约，未知字段/秘密/原文不进入日志；原始 stdout/stderr 不保存或返回。最多 16 KiB 输出、50 条脱敏日志、每条 160 字；超出输出或超时终止自身进程组并保存结果。
子进程输入为私有快照，真实项目不被命令改动。静态 CSP sandbox allow-same-origin，禁脚本、自动刷新、连接、表单与框架等外发渠道，只提供所选 HTML/CSS；不冒充动态应用或登录/云部署验证。

## 八、Prompt 设计
无新增 Prompt。配方由确定性代码声明，模型不能增添参数、解除保护或批准命令。

## 九、验收界面
从执行页进入命令页，选择任务、配方及显式文件，预览命令/来源/产物/费用/恢复/限制，核对后勾选确认并写依据，再启动。
运行详情自动有限轮询到结束，展示所属项目、步骤、开始/结束、退出码、错误、产物、脱敏日志；服务展示端口、健康与“停止本次预览”。
输入改动后不能启动旧预览，错误保留输入，重复网络请求复用幂等键。历史状态不等于当前代码有效或阶段通过。
