# 阶段 2 A1 技术开发文档 项目登记与只读接入

日期：2026-10-08。依据：主 PRD V1.1、已确认的技术适配声明、通用手册第二与第三部分。

## 一、阶段目标

实现本机项目列表、新建项目、已有目录只读预览、确认接入与刷新恢复。范围对应 FR01、FR02 的基础接入部分及必要 FR14/FR24；FR02 的资料语义冲突分析、Git 工作区完整差异和单项重新解析留在 A2，不宣称 FR02 全部完成。

主链路：填写项目资料和目录 → 预览将创建的文件或只读资料清单 → 人工点击确认 → 项目入库 → 刷新及服务重启后可查看。

本轮不实现需求生成、模型调用、基线冻结、任务执行、预算调用、阶段闸门或完整前端导航。它们仍保留在首版后续子阶段。

## 二、技术适配摘要

采用已确认的 Python/FastAPI/Pydantic、SQLite/SQLAlchemy/Alembic 与 Next.js/TypeScript/Tailwind。最小正式 Web 切片只覆盖项目登记和接入。令牌、Host/Origin 与规范路径检查在首次接入入口即生效。

## 三、技术栈与模型

后端使用 Python 3.12，测试 pytest，检查 Ruff 与类型检查；DOCX 使用 python-docx，文本 PDF 使用 pypdf。前端 npm 单一包管理器，锁定实际安装依赖。

本轮没有模型、Prompt 或 SSE。模型能力展示未启用，不返回生成结果。真实模型在后续 AI 链路实测；本轮真实模型冒烟在闸门表保持“待验（本轮未接入）”，不写“是”，也不宣布阶段 2 已完成。

## 四、环境与配置

后端 127.0.0.1:8765，前端 127.0.0.1:3000。授权根目录默认仅本工程；管理员配置可追加根目录，接入其他项目时先确认目录授权。本轮自动检查只使用工程内演示目录或临时测试目录。

本地 SQLite、预览和后端访问令牌存放在已被忽略的 `data/`；令牌自动生成、权限 0600，仅后端与前端服务端读取，浏览器不得收到令牌。配置样例不含任何真实秘密。无须产品负责人提供模型 Key。

## 五、项目结构

- `backend/app/`：配置、安全、数据库、结构定义、资料扫描与 API。
- `backend/alembic/`：版本化初始数据库迁移。
- `backend/tests/`：幂等、恢复、路径、文件与错误检查。
- `frontend/app/`：最小工作台及服务端 API 代理；代理的后端令牌不会进入客户端包。
- `scripts/`：启动和验证入口；不在接入时运行旧仓库脚本。
- `data/`：仅本地运行状态，不入仓库或交付包。

## 六、数据、资产与状态

| 实体 | 核心字段 | 约束 |
| --- | --- | --- |
| Project | id、name、description、target_user、core_task、canonical_path、template_version、delivery_target、created_at、revision | canonical_path 唯一；本轮状态为已登记，不代表开发或验收通过 |
| Preview | id、kind、request、manifest、content_hash、created_at、confirmed_project_id | 新建或接入预览持久化；确认前重新核对目录与摘要；不保存完整文档 |
| RequestRecord | key、request_hash、response | 副作用确认幂等；同键不同内容冲突；与项目在同一数据库事务提交 |
| AuditEvent | id、project_id、action、time、details | 仅记录责任动作与摘要，无秘密或全文 |

扫描索引保存相对路径、类型、大小、摘要、解析状态与字符数量，不保存全文；排除 .env、私钥、依赖、构建、平台 data 与 Git 内部内容。安全文件名及规范路径检查不允许越界符号链接。

新建采用本工程模板，在暂存目录准备 README、规则卡和 PRD 模板，再落地为原来不存在的目录；落地或数据库提交失败时仅恢复本操作创建的目录，禁止删除已有内容。预览不创建目标目录。

接入仅写工厂数据库，原目录零写入。单文档 20 MB、批次 100 MB、最多 500 个候选文件；超过上限明确拒绝或提示缩小范围，不静默截断。损坏文件逐项标记失败，扫描 PDF 标为需人工转写；解析错误不回显文档原文。UTF-8、DOCX ZIP 结构、PDF 签名分别检查真实类型，ZIP 展开量设上限。

## 七、API 与错误

接口前缀 `/api/v1/factory`；JSON 请求严格结构，拒绝多余字段。变更需服务端访问令牌及允许 Origin；前端代理同样校验 Host/Origin，使用本机服务端令牌访问后端。

| 方法与路径 | 请求 | 响应 | 主要错误 |
| --- | --- | --- | --- |
| GET /health | 无 | status、schema_version、model_enabled=false | SERVICE_UNAVAILABLE |
| GET /settings | 无 | allowed_roots、默认目录、模型未启用状态 | FORBIDDEN |
| GET /projects | offset、limit、q | items、total | INPUT_INVALID |
| GET /projects/{id} | UUID | 项目详情 | NOT_FOUND |
| POST /projects/create-preview | name、description、target_user、core_task、path、template_version、delivery_target | preview_id、content_hash、planned_files、request | PATH_FORBIDDEN、DIRECTORY_CONFLICT |
| POST /projects/import-preview | 相同项目资料，path 指向已有目录 | preview_id、content_hash、manifest、warnings、request | PATH_FORBIDDEN、INPUT_INVALID、SCAN_LIMIT |
| POST /projects/confirm | preview_id、expected_hash；Idempotency-Key | project | PREVIEW_CHANGED、IDEMPOTENCY_CONFLICT、DIRECTORY_CONFLICT |

统一错误 `{"error":{"code":"…","message":"…"}}`，不包含堆栈、秘密或完整文档。过期预览 24 小时后拒绝确认，重新预览；预览确认后同请求幂等返回原项目。

接入确认必须重新扫描，摘要包含文件内容及路径和解析结果。重复规范路径关联原项目或明确冲突；名称允许重复。SQL 唯一约束与事务防止并发重复登记。

## 八、Prompt 设计

不适用。本轮为确定性工程链路，不生成模型候选、不外发资料。

## 九、最小正式交互

项目列表显示目标、目录、登记时间和本轮已登记状态；支持搜索与详情。登记表单可选择新建或已有目录，点击预览后显示文件、异常与缺失资料，点击确认后才写入。预览期间禁止重复提交，失败保留输入，刷新失败保留旧列表并标示更新时间，旧预览不能直接确认。

页面明确“模型未启用”“本轮只登记与接入”；不把没有实现的阶段、任务或效果显示为完成。验证 390/768/1280/1440 CSS 像素、200% 缩放与键盘核心交互。

## 十、测试要求

自动测试覆盖无令牌/异常来源/异常 Host、严格输入、目录穿越与越界符号链接、秘密排除、格式伪装、损坏文件、20/100 MB 限制、超过候选数、新建不覆盖、预览不写入、确认前外部修改、确认幂等和同键异体冲突、并发登记、数据库重开恢复和迁移。

真实工程冒烟使用本工程内演示目录，从页面预览与确认，刷新并重启后端后核对项目仍存在；接入前后文件摘要相同。Browser 验证使用 ego-browser 技能，保存无秘密的页面截图。命令输出和日志不存入证据包。

本轮没有 Mock 模型结果。后续真实模型检查继续待验，不以本轮工程通过替代整个平台或 AI 验收。

## 十一、产品负责人验收

- 打开工作台，看到项目列表与模型未启用说明。
- 点新建，填名称、目标和本工程下不存在的目录；点预览，看到将创建的文件；确认后列表出现项目。
- 点接入，填本工程或已授权目录；预览可见 DOCX 等资料状态，秘密文件不在清单；确认前目录不变。
- 确认后刷新，项目仍可见；同一目录再次接入不会重复登记。
- 预览后修改资料再确认，应提示重新预览。
- 重启服务，项目仍在；页面小屏和键盘操作可用。
