## 一、阶段目标

建立 5—10 条代表样例的版本化评测计划，分别记录样例来源（真实业务/公开/合成）和模型来源（Mock/真实本地/真实云/降级模板），逐条输入、期待与产物、来源定位、模型/提示词/知识版本可追溯。本机产品负责人采用 1—3 分、不超过五维的人工评分，硬错误及理由另列，首次评分与改判不覆盖。标准先提议，经产品负责人明确确认才生效；不足真实样例或未评分保持待验。相关版本变化旧评分需复验。

本轮不调用模型、不改变现有外发与费用授权，不实现 FR17 阶段验收或 FR18 缺陷关闭。真实调用沿用 A2 具体预览/批准与预算。当前没有 Key，真实效果不能交付通过结论，D2 仍待真实打分。有限本地模型的来源报告可记录但平台未独立运行，不能冒充云冒烟或本平台真实验证。

## 二、技术适配摘要

沿用 FastAPI/SQLite/Next.js 与本机访问保护，复用追加 RequirementRecord，无迁移、依赖、服务或新增费用。后端能力及最小验收界面纵向切片，不建设完整正式前端。

## 三、技术栈与模型

Python 3.12、Node.js 22 和原锁定依赖。自动来源引用现有需求分析成功运行，不启动新请求；来源由持久运行与回执确定，客户端不能选择真实云标签。手工 Mock/本地/降级产物明确为人工来源报告，不能单凭填写或 Key 算真实验证。

## 四、环境与配置

## 六、数据、资产与状态

evaluation_plan / evaluation_score / evaluation_standard，schema_version=1，均追加保存。计划修订、前版、改动理由、需求/模型/Prompt 摘要、可选知识快照、5—10 个唯一样例 S1…、1—5 个唯一评分维度和可空阈值。每个手工样例记录期待、输入/产物、样例来源/定位、模型来源/型号/提示词/知识版本；平台样例由同项目已成功运行的输入和结构候选确定性提取，保存运行/预览/回执指纹、用量/成本/重试结构观察，不允许手工宣称真实云。

评分绑定当前计划摘要和样例，完整严格整数 1—3，固定本机产品负责人身份、明确确认、不能接受/错误事实/隐私泄露/非法动作及理由。每条评分需上次评分 ID 防止并发覆盖，改判须写理由；数量约束的满足/不满足/未评估及理由单列，不作为结构失败自动重试；首次失败和反例留在历史。模型/提示词/知识/样例/标准改变产生新计划，所有旧评分需复验；当前依赖变化也阻塞旧计划写入。配置密钥不作为有效性或真实运行证据。

均分仅展示，不能抵消硬错误。阈值按每条样例的维度均分判定，硬错误独立失败；不得用整体平均掩盖单条不能接受。项目标准确认必须有本计划 5—10 条不同真实云运行的真实业务/公开样例、可核对成功回执与完整当前人工评分，显式阈值及理由，由本机产品负责人确认，确认时锁定实际审阅评分 ID，评分变化需重新核对。重复运行或重复输入不能凑足代表样例。手工本地来源报告、Mock、合成与降级单列统计，不纳入本平台真实云标准确认。此为现有仅云模型接入的范围限制；不冒称通用本地模型执行或 FR16 实际效果已验收。

## 七、API / 工具设计

GET /api/v1/factory/projects/{id}/evaluation：当前依据摘要、最新计划/评分/标准、四类来源分组、真实待验原因、不可变历史、可选成功运行和知识快照。GET .../assets/{id}：归属校验历史。
POST .../plans：expected_revision、expected_basis_hash、5—10 samples、dimensions、minimum_score（null 或 1—3）、context_id、reason。样例 platform_run 只填 run_id 与来源/期待，原输入/输出/模型由后端提取；operator_report 不能填 real_cloud，需脱敏输入/输出与版本。
POST .../scores：plan_id、expected_hash、sample_id、previous_score_id、scores（维度完整且1—3）、hard_errors、quantity_compliant（严格bool/null）、quantity_reason、reason、confirmed=true；服务端固定 reviewer=local_operator。
POST .../standards：plan_id、expected_hash、expected_score_ids、confirmed=true、reason；确定性核对真实证据与现有评分，追加人工标准确认，不执行模型、不验收阶段。

POST 均本机访问保护、Origin 与幂等；GET 只读。统一 error.code/message：INPUT_INVALID、NOT_FOUND、REVISION_CONFLICT、EVALUATION_STALE、REAL_SAMPLES_PENDING、CONTEXT_EXCLUDED。代理写请求最多1MiB，字段长度/样例数另受限，拒绝秘密和个人信息，审计只 ID/类型不记文档；无新 SSE/长任务/外部工具。
