# LaunchFlow｜AI Coding 产品工厂与 Harness 工具链

AI 产品经理｜Avenloop AI｜AI 产品构建工具链

**项目背景**

针对多个 AI 产品开发中需求材料重复准备、实现偏离范围及验收标准不统一的问题，建立从需求定义、任务拆解到辅助开发、评审修复与交付验收的工作流程。

**核心职责**

- **AI 产品需求定义与范围管理** 将产品想法转化为用户任务、功能范围和阶段目标，开发前明确 PRD 与验收条件；依据产品目标判断功能取舍，及时识别需求遗漏与范围偏移。
- **AI Coding 启动模板与工作流复用** 复用 ai-product-starter-kit、agent-blueprint 的模板及工作流资料，统一需求、任务和验收材料，减少项目启动时的重复准备与沟通。
- **AI Coding 实现推进与产品验收** 使用 Codex、DeepSeek 辅助任务拆解、代码实现和问题修复，承担产品判断、范围确认及最终验收，跟进实现结果与需求之间的偏差。
- **Harness 执行约束与上下文接续** 通过规则卡、项目状态文件、决策台账和阶段验收清单，明确 AI 开发任务的修改范围、上下文、预期产物及暂停条件；项目切换时依据已记录状态接续任务，复用有效决策与执行约束。
- **AI 开发评审与反馈迭代** 将需求检查、辅助实现、测试评审、缺陷修复及回归验收串成反馈循环，根据执行结果调整后续任务；保留问题、修改及复测记录，以验收证据判断阶段是否完成。

**项目成果**

面向多产品研发与交付，将需求确认到首版验收的平均周期从 15 个工作日缩短至 9 个工作日，单次交付人工投入从 40 人时减少至 28 人时；首次验收通过率从 60% 提高至 80%，在人员投入不变的情况下，月均通过验收的功能版本从 2 个增加至 3 个。
