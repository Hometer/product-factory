4. 选择“平台补充 失败 · ce145163”，再选“平台补充 通过 · 9b158a82”。前者语法失败、后者修复后 1/1；来源是平台已完成受控运行，类别是**补充语法/格式**，不能使七项测试、类型、Lint 或构建自动通过。原始命令运行分别 ca53f80c… 退出 1 和 b91db422… 退出 0。
5. 旧记录显示“需复验”且保留原失败/通过算对：当前计划已有新版本，显式文件也曾再次变化。新报告必须先核对当前计划，不能继续拿旧计划录入。第三版保存了当前文件版本，但没有伪造执行结果。
6. 如只想看页面，请保持不填写。实际执行者填写时，两个表单的未保存输入会互相保护；“放弃未保存输入并还原”只清未保存文字，历史不删。取消离开可保留输入；保存冲突/来源变化提示后先刷新核对，平台不会自动重复运行工程。

反馈重点：能否分清“待验、人工报告、平台补充、当时结果、当前需复验”。这里不要求你运行脚本、准备真实模型 Key 或批准额外费用。
