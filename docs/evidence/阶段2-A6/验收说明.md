## 打开与核对

本机服务已保留。打开 [A6 合成命令演示](http://127.0.0.1:3000/projects/d71bb2f5-5dc2-46e2-b806-a4d363809f0e/commands)。若服务已关闭，在 Finder 打开产品工厂项目文件夹，双击“启动产品工厂.command”，看到“产品工厂已启动”即可。

1. 在“运行记录”找到 Python 语法检查。应显示“配方检查通过 · 仍需验收”、开始/结束时间和退出码 0；展开“查看检查、日志与产物”，应看到 sample.py 通过、进程归属及 result.json 指纹。
2. 找到 JSON 格式检查。应显示“配方未通过”、退出码 1；展开详情，应看到 bad.json 在第 1 行、第 10 列失败。点“查看结果产物”，应看到 valid=false、JSON_SYNTAX 及退出码 1，完整输入正文不会返回。
3. 找到两条 HTML/CSS 静态预览。现在均应显示“已停止”、端口 4200、结束时间和退出码 -15。实际运行时的归属/端口/健康及真实静态页面见下方截图；停止后不再提供活动预览链接。
4. 在“预览历史”查看具体配方，核对项目、步骤 E1、输入指纹、来源版本、验收要求、限制和人工确认。已经运行的预览不能再次启动，重新验证需要新预览与新确认。环境只有 15 分钟有效，过期或配方版本变化会明确阻止旧预览，不影响历史阅读。
5. 将浏览器窗口缩窄或用手机宽度查看页面，确认文件勾选框、记录和历史按钮可以换行。修改端口后尝试返回执行计划，应提示未保存；取消离开后输入仍保留，旧预览不能启动。
6. 刷新页面，应仍看到 5 份命令预览、4 条运行（Python 通过、JSON 失败、两条静态已停止），不会增加运行。最终真实重启后的记录见截图 11。

资料明确为独立合成演示，未操作其他业务工程。三种配方只解析或服务所选快照，不能代替项目单元测试、构建、动态应用及业务验收；任意脚本、安装、发布仍为手动执行待核对。业务项目要运行时，先由执行者核对并刷新来源，产品负责人在界面批准具体配方；不要求产品负责人修改文件或复制技术命令。
