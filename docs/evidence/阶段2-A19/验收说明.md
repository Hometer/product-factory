# A19 备份导出与归档：核对说明

这是 PRD FR23 的本机工程与证据交付，演示资料为合成资料。原有待验继续保留；真实模型与样例评分待验，未宣布 A19 或阶段 2 通过。

## 打开并核对
1. 已保留本机服务，打开 http://127.0.0.1:3000 。未启动时在 Finder 双击项目根目录“启动产品工厂.command”，看到首页为正确。
2. 打开[原合成项目备份页](http://127.0.0.1:3000/projects/ea1c5c20-652c-4d0b-94c7-5b663a01ea15/backups)，展开“已导出备份”，看到 5 个安全文件包含、大文件和敏感资料未包含，点击“下载此版本备份”会下载 .pfbackup.json。
3. 点“上传并预检”，选择下载的备份，填写允许根目录内、父目录已存在的全新绝对路径；写具体理由并勾选负责人确认，再点“确认上传并预检”。应先看到新增范围和替换 0；此时目录尚未创建。已有目录或损坏包会拒绝，输入保留。恢复操作会创建新项目，请只使用要恢复的资料和全新目录。
4. 查看[已恢复的新项目](http://127.0.0.1:3000/projects/05d39fa9-39a3-45f2-831c-a2302333cdbb/backups)：身份与原项目不同，5 个文件已恢复；点“查看原业务历史快照”，旧需求/决策/验收/费用是只读来源，不是当前授权或通过结论。进入新项目需求页应为修订 0，需要重新确认；秘密需重新配置。
5. 原项目点“归档管理”，选择归档，写理由、确认。首页勾选“查看已归档项目”才能在归档列表看到它，原文件和历史保留；归档后新增需求体检被拒绝。选择取消归档后，仅恢复可见性，旧暂停/取消任务不自动运行。当前演示最终已取消归档；既有归档历史仍可展开核对。
6. 未提交输入时刷新不丢理由；旧绑定变化会提示重新核对并明确采用，离开或切换可取消。活动/暂停/未知运行的归档阻断由隔离契约测试验证，演示没有真实模型、收费或未知外部请求。
