## 打开与照着点
服务保留在本机 <http://127.0.0.1:3000>。停止后，在 Finder 打开本项目文件夹，双击“启动产品工厂.command”；看到“产品工厂已启动”后打开下面地址。

1. 打开[实际恢复演示](http://127.0.0.1:3000/projects/df594f76-2387-44f3-b5cd-2e978b9e3427/recovery)。应看到同一原任务 bfe617ef…、退出码 0、sample.py 检查通过、9 个检查点；1/1 只表示本次配方结果。此演示已经接续成功，不提供重新执行旧成功任务按钮。
2. 在右侧往下看接续历史：原批准与入队、重启核对、人工核对、确认继续、启动意图、真实执行、终结结果。展开“查看版本与结果指纹”，可核对原任务和检查点；旧批准未覆盖。
3. 打开[结果未知演示](http://127.0.0.1:3000/projects/67300d6e-8995-46be-a530-6b304e9b209d/recovery)。这是明确标名的合成故障资料，没有真实外部调用。应看到原任务 11ab701a…、结果未知、0/1、4 个检查点，没有“确认继续原任务”按钮。
4. 在未知页的“本次核对或继续依据”填“已核对合成故障，结果未知不能重发”，点“保存恢复核对（不执行）”。应只新增核对记录，仍为未知，不能改成成功或解除占用。你提交后检查点数量会增加。
5. 点“刷新持久记录”，任务 ID 保持。填了依据后点返回，取消离开提醒，输入应保留。原授权/环境/文件已变化时，即使确定未执行也不能继续。
6. 外部模型区只读。未知结果需提供方查询/费用对账；这些处理能力未接入，不能自动重发或释放预留预算。本轮未启用真实模型。
