# 阶段 2 A1 验收说明

日期：2026-10-08。本轮工程已实现并验证，尚未宣布 A1 或阶段 2 通过。范围与接口见[开发文档](../../阶段文档/阶段2-A1-项目登记与只读接入.md)。没有真实模型结果，也没有用模拟生成结果充当验收。

## 打开与核对

1. 在 Finder 打开项目根目录，双击 `启动产品工厂.command`。看到“产品工厂已启动”后，在浏览器打开 <http://127.0.0.1:3000>，应看到“模型未启用”和项目列表。
2. 本机已有“演示产品”“界面创建演示”。点击卡片，应看到目标用户、核心任务、说明与目录；登记状态不代表研发完成。截图[重启后项目详情](./重启后项目详情.png)记录了服务停止后经统一启动器重开，再刷新页面仍可读取两条登记。
3. 点“新建项目”，名称填“我的核对项目”，目标用户填“产品负责人”，核心任务填“核对项目登记”。目录保留当前授权根目录，末尾的 `/新产品` 改为 `/我的核对项目`，必须是尚不存在的目录。点“预览并核对”，应看到 README、规则卡和 PRD 模板等四个文件；点“确认创建”后才创建目录并出现项目卡片。已有目录会明确拒绝覆盖。
4. 点“接入已有目录”，填写资料，目录可从“演示产品”卡片复制。点预览应看到资料清单，再点“确认接入”。同一目录关联原项目，不新增重复登记；不会改写原资料。不要使用未授权目录或真实敏感资料作为演示。
5. 按浏览器刷新，登记仍在。回到启动终端按 Control+C，看到关闭提示，再双击启动文件，登记仍在。
6. 在搜索框输入项目名称，按 Enter，应只显示匹配项目；输入不存在的名字应看到空结果说明。Tab 可以移动到搜索按钮。
7. 缩窄浏览器，表单与项目列表应上下排列；原生 200% 缩放请在浏览器菜单的缩放处调到 200%，检查文字、输入和确认按钮是否可使用，并反馈结果。原生缩放与实际手机反馈仍待验。

演示项目是真实本地目录和数据库记录，均在被忽略的 `data/`，不会出现在 Git 提交或新电脑中。当前核对只涉及登记与接入，不需要模型 Key。
